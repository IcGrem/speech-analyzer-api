# Speech Analyzer API

Система автоматизированного сбора и анализа речевых данных с использованием ML-технологий.

## Документация

Для подробного ознакомления с различными аспектами системы используйте следующие файлы:

*   [**SYSTEM.md**](./SYSTEM.md) — Общее техническое описание работы системы, архитектура и основной пайплайн данных.
*   [**DEPLOY.md**](./DEPLOY.md) — Пошаговое руководство по развёртыванию на Ubuntu (NVIDIA GPU, CUDA, Docker, Nginx, Supervisor).
*   [**ENDPOINTS.md**](./ENDPOINTS.md) — Полный список и спецификация доступных API эндпоинтов (`/api/v1`).
*   [**ML_README.md**](./ML_README.md) — Подробное описание ML-конвейера: VAD-сегментация, диаризация, ASR (Speech-to-Text) и LLM-анализ.
*   [**SERVICES_README.md**](./SERVICES_README.md) — Карта сервисного слоя приложения: бизнес-логика, планировщик задач и интеграция с внешними API.
